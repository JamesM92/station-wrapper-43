Lists & files

Build the lists a station plays from. Pick videos or whole folders on the left and add them to a list on the right. Nothing is copied: a list holds links, so a video can be in as many lists as you like and your media is never touched.

YouTube (TubeArchivist)

TubeArchivist stores videos in folders named UC… with no readable titles. Switch this on and the wrapper builds a readable version as links (a folder per channel, with seasons and episode names) that shows up in Media as a folder named after yours with -nfo added (youtube becomes youtube-nfo), and your original folder is hidden there. Add more than one library if you have them. Your TubeArchivist files are only read, never changed.
